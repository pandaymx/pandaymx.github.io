# MySQL 基础教程

MySQL 是全球最受欢迎的开源关系型数据库管理系统之一，以其高性能、高可靠性和易用性广泛应用于各类 Web 应用程序中。本文档面向初次接触 MySQL 的开发者，指导您完成从安装到基本操作的全过程。

## 1. MySQL 简介

### 历史与生态

MySQL 最初由瑞典 MySQL AB 公司开发，后被 Sun Microsystems 收购，最终归入 Oracle 公司旗下。虽然经历波折，但其社区版依然保持开源。随着时间推移，MySQL 生态发展出许多强大的组件，如用于高可用的 MySQL Group Replication、用于路由代理的 MySQL Router 等。

### MySQL vs PostgreSQL 选型建议

在进行技术选型时，MySQL 和 PostgreSQL 经常被放在一起比较：

- **MySQL 优势**：极高的查询（读）性能，生态成熟稳定，文档和社区支持庞大，上手极快。
- **选型建议**：如果你的应用是典型的 Web 应用（如电商网站、内容管理系统），以“读多写少”为主，且不需要极为复杂的事务逻辑，MySQL 通常是最佳选择。对于需要处理复杂空间数据或高级聚合分析的场景，PostgreSQL 可能更具优势。

## 2. 安装与配置

### Docker 快速启动

利用 Docker，可以在数秒内部署一个干净的 MySQL 实例供本地测试使用：

```bash
# 启动 MySQL 8.0 容器并设置 root 密码
docker run -d \
  --name my-mysql \
  -e MYSQL_ROOT_PASSWORD=mysecretpassword \
  -p 3306:3306 \
  mysql:8.0
```

### Linux 包管理器安装 (Ubuntu/Debian)

如果在 Linux 服务器上直接安装，可以使用包管理器：

```bash
sudo apt update
sudo apt install mysql-server
```

### 服务管理与配置文件

Linux 下通过 `systemctl` 管理服务：

```bash
sudo systemctl start mysql
sudo systemctl enable mysql
```

MySQL 的核心配置文件通常位于 `/etc/mysql/my.cnf` 或 `/etc/my.cnf`。

### 客户端连接

使用自带的命令行客户端连接数据库：

```bash
# -u 指定用户，-p 提示输入密码
mysql -u root -p
```

## 3. 数据库与表操作

### 创建数据库

为了支持多语言字符（如 Emoji 表情），建议在创建数据库时明确指定 `utf8mb4` 字符集。

```sql
CREATE DATABASE mydb CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 切换到刚创建的数据库
USE mydb;
```

### 创建表与数据类型

MySQL 提供了丰富的数据类型。主流的存储引擎有 InnoDB（支持事务，默认引擎）和 MyISAM（不支持事务，读性能高，较少使用）。

```sql
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,            -- 自增主键
    username VARCHAR(50) UNIQUE NOT NULL,         -- 变长字符串
    email VARCHAR(100) NOT NULL,
    age INT DEFAULT 18,                           -- 带有默认值的整数
    profile_data JSON,                            -- JSON 数据类型
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP -- 自动记录创建时间
) ENGINE=InnoDB;
```

### 约束讲解

- `PRIMARY KEY`：唯一标识表中的记录。
- `AUTO_INCREMENT`：自动生成递增的数字，通常用于主键。
- `UNIQUE`：保证字段值的唯一性。
- `NOT NULL`：该字段必须有值。
- `DEFAULT`：当未提供值时，使用设定的默认值。

## 4. CRUD 基础

### INSERT (插入)

```sql
-- 单行插入
INSERT INTO users (username, email, age)
VALUES ('alice', 'alice@example.com', 25);

-- 批量插入 (性能更好)
INSERT INTO users (username, email, age)
VALUES
    ('bob', 'bob@example.com', 30),
    ('charlie', 'char@example.com', 35);

-- 插入或更新 (ON DUPLICATE KEY UPDATE)
-- 如果遇到主键或唯一索引冲突，则执行 UPDATE
INSERT INTO users (id, username, age) VALUES (1, 'alice', 26)
ON DUPLICATE KEY UPDATE age = 26;
```

### SELECT (查询)

```sql
-- 查询指定列
SELECT username, email FROM users;

-- 带条件、排序和限制
SELECT * FROM users
WHERE age > 20
ORDER BY created_at DESC
LIMIT 10;

-- 去重查询
SELECT DISTINCT age FROM users;
```

### UPDATE (更新)

```sql
UPDATE users
SET age = 28, email = 'newalice@example.com'
WHERE username = 'alice';
```

### DELETE vs TRUNCATE

```sql
-- DELETE: 逐行删除并记录日志，可以使用 WHERE 条件
DELETE FROM users WHERE age < 18;

-- TRUNCATE: 快速清空全表数据，重置自增 ID，且无法回滚
TRUNCATE TABLE users;
```

## 5. 查询技巧

### 多表连接 (JOIN)

连接用于结合两个或多个表的行。

```sql
-- 内连接：返回两表中都有匹配的行
SELECT u.username, o.order_total
FROM users u
INNER JOIN orders o ON u.id = o.user_id;

-- 左连接：返回左表所有行，即使右表中没有匹配
SELECT u.username, o.order_total
FROM users u
LEFT JOIN orders o ON u.id = o.user_id;
```

### 分组与聚合

```sql
SELECT age, COUNT(*) as user_count
FROM users
GROUP BY age
HAVING COUNT(*) > 1;
```

### 模糊查询与分页

```sql
-- LIKE 模糊匹配 (% 代表任意数量字符)
SELECT * FROM users WHERE username LIKE 'al%';

-- LIMIT 分页 (跳过前 20 条，取 10 条)
SELECT * FROM users LIMIT 20, 10;
-- 注意：LIMIT OFFSET(深度分页) 在偏移量很大时性能会下降
```

## 6. 索引基础

### B-tree 索引

MySQL 默认使用 B+tree 数据结构存储索引。索引能极大加快数据检索速度，但会占用磁盘空间并轻微降低写入性能。

### 创建与查看索引

```sql
-- 创建普通索引
CREATE INDEX idx_email ON users(email);

-- 创建复合索引 (包含多个列)
-- 注意最左前缀原则：查询条件必须包含最左边的列 (age) 索引才会生效
CREATE INDEX idx_age_username ON users(age, username);

-- 查看表上的索引
SHOW INDEX FROM users;
```

## 7. 用户与安全

保护数据库免受未经授权的访问至关重要。

### 创建用户并授权

```sql
-- 创建新用户 (指定可以从任意主机 '%' 登录)
CREATE USER 'app_user'@'%' IDENTIFIED BY 'StrongPassword123!';

-- 授予该用户对 mydb 数据库下所有表的读写权限
GRANT SELECT, INSERT, UPDATE, DELETE ON mydb.* TO 'app_user'@'%';

-- 刷新权限使其生效
FLUSH PRIVILEGES;
```
