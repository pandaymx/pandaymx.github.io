# Oracle 基础教程

Oracle 数据库是由 Oracle Corporation 开发的业界领先的商用对象-关系型数据库管理系统 (ORDBMS)。凭借其卓越的稳定性、强大的并发处理能力和丰富的高级特性，Oracle 广泛应用于全球的金融、电信、政府及大型企业核心业务系统中。

## 1. Oracle 简介

### 版本与 Editions

Oracle 发展至今经历了多个重要版本，目前企业主流使用的是 19c（长期支持版）及 23c 等版本。"c" 代表 Cloud，强调了对云计算的深度整合。

- **Enterprise Edition (EE)**：企业版，包含所有高级特性（如 RAC 集群、Data Guard 等），价格高昂。
- **Standard Edition 2 (SE2)**：标准版，适合中小型企业，具有 CPU 核心数限制，不包含企业版的高级选件。
- **Express Edition (XE)**：快捷版，完全免费供开发、学习甚至小型生产使用，但有严格的资源限制（如最大 2 CPU 核心，2GB 内存，12GB 用户数据）。

### Oracle vs 开源数据库 (MySQL/PostgreSQL)

- **优势**：极度成熟的优化器、完善的 PL/SQL 编程支持、真正意义上的最高可用性架构（RAC）、以及强大的官方支持服务。
- **劣势**：高昂的授权费用、运维复杂度高、较为封闭的生态体系。

## 2. 安装与连接

### Docker 快速启动 Oracle XE

在本地开发和学习时，最推荐使用官方提供的 Oracle XE Docker 镜像：

```bash
# 下载并启动 Oracle 21c XE 容器
# 注意：Oracle 容器初始化通常需要数分钟，请耐心等待
docker run -d \
  --name oracle21c \
  -p 1521:1521 \
  -e ORACLE_PASSWORD=my_strong_password \
  gvenzl/oracle-xe:21-slim
```

### 客户端连接工具

- **Oracle SQL Developer**：官方免费提供的跨平台图形化管理工具，功能极为强大。
- **SQL\*Plus**：随数据库自带的经典命令行工具，也是 DBA 最常使用的工具。
  ```bash
  # 连接到本地数据库实例
  sqlplus system/my_strong_password@//localhost:1521/XEPDB1
  ```

### 概念解析：CDB 与 PDB (12c+)

从 Oracle 12c 开始引入了**多租户架构**：

- **CDB (Container Database)**：容器数据库，包含整个数据库的元数据和系统配置。
- **PDB (Pluggable Database)**：可插拔数据库。用户的数据和应用实际上存在于具体的 PDB 中。连接应用时，应直接连接到相应的 PDB（如上述连接串中的 `XEPDB1`），而不是根容器 (CDB$ROOT)。

## 3. 表空间与用户管理

Oracle 的存储和权限管理与 MySQL 等不同，它是基于表空间（Tablespace）和模式（Schema/User）的。

### 表空间概念

表空间是数据库的逻辑存储容器，它由底层的物理数据文件（Datafile）组成。

- **SYSTEM / SYSAUX**：存储数据库的系统数据字典和运行元数据。
- **TEMP**：用于存放排序操作、哈希连接时产生的临时数据。
- **UNDO**：存放旧版本数据，用于事务回滚和读一致性。
- **USERS**：通常用于存放普通业务数据。

```sql
-- 创建自定义表空间
CREATE TABLESPACE app_data
DATAFILE '/opt/oracle/oradata/app_data01.dbf'
SIZE 100M AUTOEXTEND ON NEXT 50M MAXSIZE 2G;
```

### 创建用户并授权

在 Oracle 中，**用户 (User) 和 模式 (Schema) 是一一对应的**。当你创建了一个用户，系统也会自动创建一个同名的 Schema 用于存放该用户拥有的表。

```sql
-- 创建用户并指定默认表空间
CREATE USER c##app_user IDENTIFIED BY "AppPwd123!"
DEFAULT TABLESPACE app_data
QUOTA UNLIMITED ON app_data;

-- 授予基础权限：连接数据库和创建基本对象的权限
GRANT CONNECT, RESOURCE TO c##app_user;
```

_(注：12c 后在 CDB 中创建公用用户需要带 `c##` 前缀。)_

## 4. 表管理与数据类型

### 常用数据类型

- **VARCHAR2(n)**：变长字符串，**强烈建议在 Oracle 中全部使用 VARCHAR2 代替 VARCHAR**。
- **NUMBER(p, s)**：高精度数值类型，可存整数和小数。`p` 为总位数，`s` 为小数位数。
- **DATE**：日期和时间类型（精确到秒）。
- **TIMESTAMP**：更高精度的时间类型（支持小数秒和时区）。
- **CLOB / BLOB**：用于存储海量文本或二进制大对象（如图片、文档）。

### 创建表与约束

```sql
CREATE TABLE employees (
    emp_id NUMBER PRIMARY KEY,
    first_name VARCHAR2(50),
    last_name VARCHAR2(50) NOT NULL,
    email VARCHAR2(100) UNIQUE,
    salary NUMBER(8, 2) CHECK (salary > 0),
    department_id NUMBER,
    hire_date DATE DEFAULT SYSDATE,
    -- 外键约束
    CONSTRAINT fk_dept FOREIGN KEY (department_id) REFERENCES departments(dept_id)
);
```

### 序列 (Sequence) 与自增主键

早期的 Oracle 没有类似 MySQL 的 `AUTO_INCREMENT`。需要通过创建序列（独立的对象）来生成递增数值。12c 之后引入了更为简便的 `IDENTITY` 语法。

```sql
-- 传统方式：创建序列
CREATE SEQUENCE emp_seq START WITH 1 INCREMENT BY 1;
-- 插入时使用：INSERT INTO employees (emp_id) VALUES (emp_seq.NEXTVAL);

-- 12c+ 新方式：直接在建表时指定为标识列
CREATE TABLE new_table (
    id NUMBER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name VARCHAR2(50)
);
```

## 5. SQL 基础

Oracle 的 SQL 语法基本符合 ANSI 标准，同时带有强烈的自身特色。

```sql
-- 插入与更新
INSERT INTO employees (first_name, last_name) VALUES ('John', 'Doe');
UPDATE employees SET salary = salary * 1.1 WHERE department_id = 10;

-- 分页查询 (12c+ 语法，极大简化了以前复杂的 ROWNUM 嵌套)
SELECT * FROM employees
ORDER BY salary DESC
OFFSET 0 ROWS FETCH NEXT 10 ROWS ONLY;

-- 字符串拼接
-- Oracle 不推荐使用 + 号拼接，必须使用 || 或 CONCAT()
SELECT first_name || ' ' || last_name AS full_name FROM employees;
```

### 常用内置函数

- **日期处理**：`SYSDATE` (当前时间), `TO_DATE('2024-01-01', 'YYYY-MM-DD')` (字符串转日期), `ADD_MONTHS(SYSDATE, 1)`。
- **空值处理**：`NVL(salary, 0)` (如果 salary 为 NULL 则返回 0)，功能同标准的 `COALESCE`。
- **格式转换**：`TO_CHAR(1234.56, '$9999.99')` (数值转字符串并格式化)。

## 6. PL/SQL 入门

PL/SQL (Procedural Language/SQL) 是 Oracle 对标准 SQL 的过程化语言扩展。它允许你将 SQL 语句和条件控制、循环、异常处理等逻辑结合在一起，在数据库服务端执行，极大提升复杂业务的处理效率。

### 匿名块结构

```sql
DECLARE
    -- 声明变量
    v_emp_count NUMBER;
    v_dept_id NUMBER := 20;
BEGIN
    -- 执行逻辑
    SELECT COUNT(*) INTO v_emp_count FROM employees WHERE department_id = v_dept_id;

    -- 条件判断
    IF v_emp_count > 10 THEN
        DBMS_OUTPUT.PUT_LINE('Department is large.');
    ELSIF v_emp_count > 0 THEN
        DBMS_OUTPUT.PUT_LINE('Department is small.');
    ELSE
        DBMS_OUTPUT.PUT_LINE('No employees.');
    END IF;

EXCEPTION
    -- 异常处理
    WHEN OTHERS THEN
        DBMS_OUTPUT.PUT_LINE('An error occurred: ' || SQLERRM);
END;
/
```

_(注：使用 SQL Developer 或 sqlplus 运行上述代码前，需要先执行 `SET SERVEROUTPUT ON` 才能看到输出结果。)_
