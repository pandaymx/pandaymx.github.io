# 计算机科学 (CS) 核心体系

欢迎来到计算机科学核心知识库。这里整理了计算机科学领域最核心的四门基础学科，内容骨架对齐全国计算机学科专业基础综合考试（408）大纲，旨在建立扎实、完整的计算机科学知识体系。

## 核心支柱

以下是构筑计算机科学知识大厦的四大基石：

- **[数据结构与算法](./data-structure/intro)**
  - 研究数据的逻辑结构、物理结构及其操作，培养高效处理数据的思维与能力。

- **[计算机组成原理](./computer-organization/intro)**
  - 深入探究计算机硬件系统的构成与工作原理，理解指令如何在底层硬件上流转执行。

- **[操作系统](./operating-system/intro)**
  - 学习计算机系统资源的管理者，掌握进程控制、内存管理、文件系统及设备管理的机制。

- **[计算机网络](./network/intro)**
  - 揭开信息交互的奥秘，解析网络分层架构、协议标准及互联网的运行机制。
