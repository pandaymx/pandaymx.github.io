# 内存与存储介质

在计算机系统中，数据的存储可以划分为“易失性存储”（内存）和“非易失性存储”（硬盘）。它们在速度、容量和用途上有着本质的区别。

## 1. 内存 (RAM - 随机存取存储器)

内存是 CPU 和硬盘之间的缓冲地带。由于 CPU 处理速度极快，而硬盘读取速度较慢，系统会将当前正在运行的程序和数据临时加载到内存中供 CPU 快速调用。断电后，内存中的数据会全部丢失。

### DDR 世代

目前主流的内存标准是 **DDR (Double Data Rate)**。

- **DDR4**：上一代主流标准，频率通常在 2400MHz 到 3600MHz 之间。
- **DDR5**：最新一代标准，起步频率极高（通常 4800MHz 以上），带宽翻倍，功耗更低，是目前新装机的首选。

### 双通道 (Dual Channel)

内存的“通道”可以理解为数据传输的公路。插两根相同规格的内存条组成双通道，相当于将数据传输的马路拓宽了一倍，能显著提升内存带宽和系统整体性能（尤其是对于使用核芯显卡的电脑）。

### 容量与延迟

- **容量**：日常轻度办公 8GB 勉强够用，主流推荐 16GB，游戏或专业生产力（如视频剪辑、虚拟机）推荐 32GB 甚至更高。
- **时序/延迟 (CL值)**：表示内存响应 CPU 请求的延迟时间。在相同频率下，CL 值（如 CL16, CL30）越小越好。

## 2. 硬盘 (存储介质)

硬盘用于长久保存操作系统、软件和用户数据。断电后数据不会丢失。

### 机械硬盘 (HDD)

依靠磁头和旋转的盘片来读写数据。

- **优点**：容量大、价格便宜、数据恢复相对容易。
- **缺点**：读写速度慢，怕震动，体积大。
- **用途**：适合作为大容量的数据仓库（如存放电影、备份文件）。

### 固态硬盘 (SSD)

使用闪存颗粒（NAND Flash）来存储数据，没有任何机械活动部件。

- **SATA SSD**：使用老式的 SATA 接口，速度受限（最高约 550MB/s），通常为 2.5 英寸外形。
- **NVMe M.2 SSD**：目前绝对的主流。使用 PCIe 通道和 NVMe 协议，外形像口香糖一样小巧。
  - **速度差异**：根据 PCIe 版本的不同，速度差异巨大。PCIe 3.0 SSD 速度通常在 3000MB/s 左右，而 PCIe 4.0 SSD 可以达到 7000MB/s 以上。
  - **优势**：极大地缩短了开机时间、软件加载速度和游戏读图时间。

总结来说，内存决定了你能“同时运行”多少程序且不卡顿，而固态硬盘决定了你“打开”这些程序和操作系统的速度有多快。
