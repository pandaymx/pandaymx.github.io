# 计算机基础操作与环境

了解硬件之后，将硬件组合起来并让操作系统正常运行，还需要一些基础的系统环境和操作知识。

## 1. BIOS 与 UEFI

在操作系统启动之前，计算机首先运行的是固化在主板芯片上的底层程序。

- **BIOS (Basic Input/Output System)**：传统的“基本输入输出系统”，界面简陋（通常纯键盘操作），由于设计老旧，存在硬盘容量支持限制和启动速度慢的问题，目前已被淘汰。
- **UEFI (Unified Extensible Firmware Interface)**：统一可扩展固件接口，是 BIOS 的现代替代品。它支持图形化界面和鼠标操作，支持超大容量硬盘，且启动速度更快（支持快速启动）。

进入 BIOS/UEFI 的方法通常是在电脑开机、出现主板 Logo 时，快速且连续地按下特定的按键（如 `Del`, `F2`, `F12` 等，具体取决于主板品牌）。

## 2. 系统引导 (Boot)

系统引导是指计算机启动时加载操作系统的过程。

- **引导顺序 (Boot Order)**：在 UEFI 界面中，你可以设置计算机寻找操作系统的顺序。例如，重装系统时，你需要将插入的 U 盘（包含安装镜像）设置为第一启动项。
- **引导分区 (EFI 启动分区)**：现代操作系统在安装时，会在硬盘上划分一个很小（约 100MB-300MB）的隐藏分区，称为 EFI 系统分区。这里存放着引导加载程序（Bootloader），UEFI 启动时会读取这里的文件来唤醒 Windows 或 Linux。

## 3. 磁盘分区类型

由于历史遗留问题和技术发展，硬盘的分区表格式主要有两种：

- **MBR (Master Boot Record)**：老式分区表。它最大只能支持 2TB 的硬盘，且最多只能创建 4 个主分区。通常与传统的 BIOS 搭配使用（Legacy 模式）。
- **GPT (GUID Partition Table)**：现代分区表标准。它突破了 2TB 的容量限制，理论上可以创建无数个分区。现代计算机几乎全部采用 **UEFI + GPT** 的组合。

## 4. 文件系统常识 (File System)

文件系统决定了操作系统如何管理和存储文件。格式化硬盘或 U 盘时，需要选择合适的文件系统：

- **NTFS**：Windows 系统最主流的文件系统。支持超大文件和高级权限管理，但在 macOS 下默认只能读不能写。
- **FAT32**：最古老且兼容性最好的格式（Windows、macOS、Linux、各种数码设备都支持）。但致命缺点是**无法存储单体超过 4GB 的文件**。
- **exFAT**：专为闪存设备（如 U 盘、SD 卡）设计的格式。解决了 FAT32 无法存储 4GB 以上大文件的缺点，同时在 Windows 和 macOS 之间拥有极佳的跨平台读写兼容性。
- **APFS / ext4**：APFS 是苹果 macOS 的现代文件系统，而 ext4 是多数 Linux 发行版的默认文件系统。它们在各自的生态内表现优异。

掌握这些基础概念，可以帮助你在遇到电脑启动失败、重装系统、或者跨设备拷贝大文件等常见问题时，快速定位并解决问题。
