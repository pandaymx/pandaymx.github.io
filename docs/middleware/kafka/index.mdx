# 🦅 Kafka

Apache Kafka 是一个开源的分布式事件流平台，被数千家公司用于高性能数据管道、流分析、数据集成和关键任务应用。

## 核心概念

- **Broker**: Kafka 集群中的一个节点。
- **Topic (主题)**: 消息的分类，生产者将消息发布到特定的 Topic。
- **Partition (分区)**: Topic 的物理划分，一个 Topic 可以有多个 Partition，提高并发和吞吐量。
- **Producer (生产者)**: 向 Kafka 发布数据的应用程序。
- **Consumer (消费者)**: 从 Kafka 订阅并处理数据的应用程序。
- **Consumer Group (消费者组)**: 一组共同消费一个 Topic 的 Consumer 集合，实现消息在组内的负载均衡。
