# ⚙️ 中间件 (Middleware)

欢迎来到中间件模块！

本专栏的定位是作为**分布式系统核心组件的实战与调优指南**，重点服务于我们的微服务架构生态。

## 🎯 包含的组件

为了确保文档的清晰度和避免内容重叠，本模块主要包含以下核心中间件的深入探讨、实战使用以及性能调优经验：

- **[🐰 RabbitMQ](./rabbitmq/)**: 高级消息队列
- **[🦅 Kafka](./kafka/)**: 高吞吐流处理平台
- **[🔍 Elasticsearch](./elasticsearch/)**: 分布式检索与 ELK 日志栈核心

> **注意**：Redis 和 PostgreSQL 等数据库相关组件，已归属于顶级的 Database 专栏，本模块不再重复建设。
