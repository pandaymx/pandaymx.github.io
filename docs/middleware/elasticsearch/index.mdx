# 🔍 Elasticsearch

Elasticsearch 是一个基于 Lucene 的开源分布式搜索和分析引擎。它通常作为 ELK（Elasticsearch, Logstash, Kibana）堆栈的核心组件，用于日志聚合、全文搜索和实时数据分析。

## 核心概念

- **Index (索引)**: 具有相似特征的文档集合，类似于关系型数据库中的数据库。
- **Document (文档)**: 可以被索引的基础信息单元，以 JSON 格式表示，类似于关系型数据库中的行。
- **Type (类型)**: (已在较新版本中逐渐废弃) 索引内的逻辑分类。
- **Node (节点)**: 集群中的一个服务器。
- **Cluster (集群)**: 一个或多个节点的集合，共同保存数据并提供联合索引和搜索功能。
