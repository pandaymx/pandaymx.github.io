# AI 知识库导读

欢迎来到 AI 知识库！本模块旨在探讨**如何利用现代 AI 技术赋能研发全流程，从本地模型微调、自动化编码到构建企业级 Agent**。

在这里，我们将深入了解人工智能的各个层面，涵盖从基础理论到实际应用的前沿技术。

## 模块导航

我们的知识库主要分为以下三个子方向：

### 1. [AI 概念 (Concepts)](./concepts/index.md)

探索人工智能、机器学习、深度学习以及大语言模型（LLMs）等核心概念，为您打下坚实的理论基础。

### 2. [AI 编程 (Programming)](./programming/index.md)

掌握如何将 AI 融入实际开发工作流。从利用 AI 辅助编写代码、调用流行的大模型 API，到本地模型部署和微调实践。

### 3. [AI 代理 (Agents)](./agents/index.md)

深入研究 AI Agent 的架构设计与应用开发。了解 Agent 如何通过利用工具、记忆系统以及规划能力来解决复杂的企业级现实问题。
